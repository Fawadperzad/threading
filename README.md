## 🚀 About The Project

This project contains several Java threading and multithreading examples.

The goal is to understand:

* Threads
* Runnable Interface
* Daemon Threads
* Multithreading
* Background Tasks
* Performance Improvements
* Swing GUI with Threads

---

## 📚 Included Examples

### Backup_Task

Simulates a background backup service using Java threads.

### CheckDaemonSimple

Simple daemon thread example.

### PiCalculatorSwing

Java Swing application for calculating PI.

### PIMultiThread

Calculates PI using multiple threads.

### PISingleThread

Calculates PI using a single thread.

### Varianten

Different threading variations and implementations.
